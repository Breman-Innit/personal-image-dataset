# Personal Image Dataset

## Overview
This repository contains a collection of approximately 1,000 self-captured images taken in different environments for learning and experimenting with Artificial Intelligence (AI) and Computer Vision using Ultralytics YOLO.

## Objectives
- Collect images in different environments and lighting conditions.
- Explore image datasets for AI and computer vision applications.
- Gain practical experience with Ultralytics YOLO.

## Dataset
- **Target:** Approximately 1,000 images
- **Subject:** Self-captured images
- **Environments:** Various locations and surroundings
- **Purpose:** Educational and AI experimentation

## Tools & Technologies
- Python
- Ultralytics YOLO
- Computer Vision
- Git and GitHub

## Disclaimer
This dataset is created for educational and research purposes as part of an AI learning exercise.
